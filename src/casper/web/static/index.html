Casper — The Friendly Ghostwriter

Casper transforms unstructured source notes into audience-adapted, format-compliant drafts grounded strictly in explicit source facts. By default everything runs 100% locally and deterministically with zero external network calls.

  • Zero invention: Every non-closing sentence cites one or more verified source fact IDs.
  • Local privacy: Private author metadata lives only in mode-0600 .local.yaml files and never leaves your machine.
  • Localhost-only server: Bound strictly to 127.0.0.1 with Host, Origin, Sec-Fetch-Site, and CSP protections.
